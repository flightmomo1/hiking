IB3W Weather-Sensitive Feature Vector v1

Activity-time weather observation vector. No risk score, no THCI, no missing-to-zero imputation.

1. Scope

This layer converts gate-approved representative weather features into a cleaner activity-level feature vector. It does not decide mountain weather risk. Antecedent precipitation and surface wetness are reserved for a later context layer.
