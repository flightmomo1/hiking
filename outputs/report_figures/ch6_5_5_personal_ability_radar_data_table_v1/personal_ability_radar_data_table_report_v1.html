CH6.5.5 Personal Ability Radar Data Table v1

PASS_CH6_5_5_PERSONAL_ABILITY_RADAR_DATA_TABLE_V1_GOVERNED_TABLE_ONLY

CH6.5.5 personal ability radar data table v1 is a governed data-table layer only. It converts an axis contract and activity/person evidence into per-activity per-axis rows for future visualization. It does not create a radar plot and does not compute or authorize radar scores, ability scores, ability ranks, ability classes, THCI scores, final hiking risk scores, route suitability scores, go/no-go decisions, medical diagnoses, or causality claims.
